PROMPT MAESTRO BACKEND
Sistema: Plataforma Integral de Gestión Juegos Evita Formosa

Objetivo:
Desarrollar un backend de producción siguiendo Clean Architecture, DDD modular y Scrum.

Stack obligatorio:
- NestJS + TypeScript
- PostgreSQL
- Prisma ORM
- Redis
- JWT + Refresh Tokens (solo administración)
- RBAC
- Docker
- Nginx
- Swagger/OpenAPI
- MinIO/S3 para archivos
- GitHub Actions
- Winston/Pino
- Validación estricta.
Seguridad:
Implementar OWASP Top 10, Argon2, Helmet, CORS, CSP, rate limiting, auditoría completa, logs estructurados, backups, versionado API, manejo centralizado de errores.
Roles:
Super Admin, Admin Provincial, Admin Departamental, Admin Zonal, Coordinador, Delegado, Entrenador, Árbitro, Operador de Mesa, Jugador (sin login), Público.
Flujo:
Jugador accede mediante QR, completa inscripción, carga documentación, queda Pendiente, Delegado revisa, Administrador aprueba, participa.
Motor configurable de competencias:
Debe soportar deportes individuales y por equipos, múltiples tipos de resultados (tiempo, goles, sets, puntos, posiciones), etapas Zonal→Departamental→Provincial, rankings automáticos, reportes CSV/XLSX.
Metodología:
Trabajar exclusivamente por épicas y sprints, mantener contexto, no romper compatibilidad, documentar decisiones, pruebas unitarias/integración, SOLID, DRY, KISS, código listo para producción.
Integración:
API REST versionada (/api/v1), OpenAPI, contratos estables, DTO compartidos, respuestas consistentes, códigos HTTP correctos, paginación, filtros, auditoría y trazabilidad.
